# План доработок интерфейса

Список того, что попросили сделать, и как это выполнено. Отметка `[x]` ставится, только когда пункт
сделан, проверен в QEMU (скриншоты) и прошёл `make test` на обеих сборках.

## Текущий заход

- [x] **Буфер обмена для картинок.** Скриншот копируется в буфер (как в Windows) — настройка
  `shotcopy`; в редакторе скриншота кнопка «Копировать»; вставка картинки в Paint (Ctrl+V);
  Photos копирует открытый снимок (Ctrl+C); программы Windows получают картинку через `CF_DIB` и могут
  положить свою; команда `clip` (`pbcopy`) показывает, задаёт и сохраняет содержимое буфера.
- [x] **Spaces — несколько рабочих столов.** В Mission Control сверху полоса столов с кнопкой «+»
  и удалением; окно можно перетащить на другой стол; переключение Win+Ctrl+←/→ с
  анимацией сдвига, Win+Ctrl+D — новый стол, Win+Ctrl+F4 — закрыть текущий (его окна переезжают на соседний); у каждого окна свой стол, Dock и переключатель окон
  знают об этом (щелчок по окну с другого стола переключает стол). Команда `desktops` (`spaces`)
  показывает столы с окнами, добавляет, переключает, удаляет и переносит окна.
- [x] **Размер ядра.** Основная система — 64-битная (это сборка по умолчанию с перехода на 64 бита).
  32-битная собирается только как дополнительный образ для старых ПК без 64-битного процессора. Чтобы
  её предел 3,5 МБ больше не мешал, значки интерфейса переехали из образа ядра в пакет
  ramdisk (`/system/icons.pak`) и загружаются при старте; у 32-битного ядра теперь запас около 330 КБ.
- [x] **Значки заново.** Все значки приложений: скруглённая форма (squircle), несколько слоёв —
  задний слой с размытыми фигурами, полупрозрачные «стеклянные» пластины, чёткий символ сверху с мягкой
  тенью; без «висты» (никакого блика по кромке и глянца).
- [x] **Виджеты растягиваются мышью.** В режиме редактирования у виджета ручки на краях и в углу:
  потянул — размер меняется по клеткам сетки (в пределах, подходящих виду); вид сам перестраивается под
  размер. Пункты размеров из правого меню убраны.
- [x] **Без теней у окон.** Открытые окна рисуются без тени.
- [x] **Строка меню сливается с окном.** Когда окно на весь экран (Full Screen или Fill Screen),
  верхняя панель берёт цвет верхней полосы окна/приложения, без разделительной линии.
- [x] **Край Liquid Glass у Dock и виджетов.** Вместо светлой обводки — настоящий край стекла:
  картинка за ним преломляется у кромки, как в толстом стекле; никакой выделенной линии.
- [x] **Из Настроек убрано то, что настраивается в другом месте.** Раздел «Виджеты» удалён полностью —
  всё в режиме редактирования виджетов; остальные панели проверены на то же.
- [x] **Рабочий стол: сетка, выделение, перетаскивание.** Значки (приложения, ярлыки, файлы) стоят на
  сетке и запоминают место; выделение рамкой, Ctrl/Shift+щелчок, перетаскивание нескольких сразу в
  свободные клетки; раскладка сохраняется для каждого пользователя.
- [x] **Часы: шрифт, цвет, стиль.** В настройках виджета часов — шрифт (несколько начертаний цифр),
  цвет (палитра), стиль (цифровые, стрелочные, с секундами/датой).

## Установка без сложностей и звук

- [x] **Готовые файлы без сборки.** GitHub Actions после каждого изменения обновляет релиз **latest**:
  `synthos-windows.zip`, `synthos-usb.zip`, `synthos-usb32.zip` и `SHA256SUMS` — скачиваются по прямой
  ссылке, без входа в Actions.
- [x] **Установка из Windows без флешки.** `Install SynthOS.cmd` (сам просит права администратора):
  сжимает C:, создаёт раздел SynthOS и пишет туда систему, кладёт загрузчик в раздел EFI Windows,
  добавляет «SynthOS» в меню загрузки (`bcdedit`) и запускает его при следующей перезагрузке;
  BitLocker приостанавливается на две перезагрузки. `Uninstall SynthOS.cmd` всё убирает и
  возвращает место диску C:. Проверка — `tests/winsim.py` в `make test-hw` (диск «как у Windows»,
  две загрузки в OVMF).
- [x] **Secure Boot можно не выключать.** Первым стартует shim (Ubuntu, подписан Microsoft), ключ
  SynthOS регистрируется один раз в MokManager прямо с флешки или из раздела EFI. Проверено в OVMF
  с заводскими ключами Microsoft (`tests/mok.py` проходит экран MokManager клавишами). Раздел EFI в
  образе увеличен до 12 МБ; старые установки (4 МБ) по-прежнему загружаются.
- [x] **SATA в режиме RAID / Intel RST.** Контроллер Intel в режиме RAID используется как AHCI;
  NVMe-диски за Intel VMD находятся драйвером `arch/x86/vmd.c`. Собранные RAID-массивы не
  поддерживаются. В QEMU нет VMD и RAID-режима, поэтому на реальном железе не проверено.
- [x] **Fast Boot можно не выключать.** Установка из Windows не нуждается в флешке; для флешки —
  Shift + «Перезагрузка» → «Использовать устройство».
- [x] **Звук на современных ПК.** Драйвер Intel HD Audio с кодеками Realtek ALC (и Conexant, IDT,
  VIA, Cirrus): поиск пути к динамикам/наушникам/линейному выходу, EAPD, переключение на наушники,
  тестовый тон `sound test`. Проверено в QEMU (`intel-hda`, запись в WAV: 440 Гц, 0,5 с, без эха).
  Нет: HDMI-звука, микрофона, особых настроек отдельных ноутбуков.
