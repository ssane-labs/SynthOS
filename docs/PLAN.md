# План доработок интерфейса

Список того, что попросили сделать, и как это выполнено. Отметка `[x]` ставится, только когда пункт
сделан, проверен в QEMU (скриншоты) и прошёл `make test` на обеих сборках.

## Текущий заход

- [ ] **Буфер обмена для картинок.** Скриншот копируется в буфер (как в Windows) — настройка
  `shotcopy`; в редакторе скриншота кнопка «Копировать»; вставка картинки в Paint (Ctrl+V);
  программы Windows получают картинку через `CF_DIB`/`CF_BITMAP` и могут положить свою.
- [ ] **Spaces — несколько рабочих столов.** В Mission Control сверху полоса столов с кнопкой «+»
  и удалением; окно можно перетащить на другой стол; переключение Ctrl+←/→ и Win+Ctrl+←/→ с
  анимацией сдвига, Win+Ctrl+D — новый стол; у каждого окна свой стол, Dock и переключатель окон
  знают об этом.
- [ ] **Размер ядра.** Основная система — 64-битная (это сборка по умолчанию с перехода на 64 бита).
  32-битная собирается только как дополнительный образ для старых ПК без 64-битного процессора. Чтобы
  её предел 3,5 МБ больше не мешал, значки и шрифты интерфейса переезжают из образа ядра в пакет
  ramdisk и загружаются при старте.
- [ ] **Значки заново.** Все значки приложений: скруглённая форма (squircle), несколько слоёв —
  задний слой с размытыми фигурами, полупрозрачные «стеклянные» пластины, чёткий символ сверху с мягкой
  тенью; без «висты» (никакого блика по кромке и глянца).
- [ ] **Виджеты растягиваются мышью.** В режиме редактирования у виджета ручки на краях и в углу:
  потянул — размер меняется по клеткам сетки (в пределах, подходящих виду); вид сам перестраивается под
  размер. Пункты размеров из правого меню убраны.
- [ ] **Без теней у окон.** Открытые окна рисуются без тени.
- [ ] **Строка меню сливается с окном.** Когда окно на весь экран (Full Screen или Fill Screen),
  верхняя панель берёт цвет верхней полосы окна/приложения, без разделительной линии.
- [ ] **Край Liquid Glass у Dock и виджетов.** Вместо светлой обводки — настоящий край стекла:
  картинка за ним преломляется у кромки, как в толстом стекле; никакой выделенной линии.
- [ ] **Из Настроек убрано то, что настраивается в другом месте.** Раздел «Виджеты» удалён полностью —
  всё в режиме редактирования виджетов; остальные панели проверены на то же.
- [ ] **Рабочий стол: сетка, выделение, перетаскивание.** Значки (приложения, ярлыки, файлы) стоят на
  сетке и запоминают место; выделение рамкой, Ctrl/Shift+щелчок, перетаскивание нескольких сразу в
  свободные клетки; раскладка сохраняется для каждого пользователя.
- [ ] **Часы: шрифт, цвет, стиль.** В настройках виджета часов — шрифт (несколько начертаний цифр),
  цвет (палитра), стиль (цифровые, стрелочные, с секундами/датой).
