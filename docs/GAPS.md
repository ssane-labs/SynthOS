# Чего нет в SynthOS по сравнению с Windows и macOS

Список составлен для версии 1.1 «Black Hole». В нём то, что есть в Windows 11 или macOS и чего пока нет
в SynthOS (или есть только заготовка). Пункты отсортированы по важности для обычного пользователя: сверху то,
без чего систему трудно использовать каждый день, внизу то, что нужно немногим.

Обозначения: **W** есть в Windows, **M** есть в macOS. «Частично» значит, что в SynthOS есть начало, но
до уровня W/M далеко.

## Что SynthOS уже умеет (для сравнения)

Свой загрузчик BIOS/UEFI с Secure Boot, 64‑битное ядро (и 32‑битное для старых ПК), установка рядом с Windows,
диски IDE/AHCI/NVMe/USB (в том числе Intel RST/VMD), звук HDA, сеть с HTTPS (TLS 1.3), рабочий стол в стиле
macOS с Liquid Glass, Dock, строкой меню, Пунктом управления, Mission Control и рабочими столами, виджеты,
снимки экрана с редактором, Quick Look, поиск, пользователи с паролями и экран блокировки, запуск 32‑ и
64‑битных программ Windows (Chromium, Firefox, установщики MSI/NSIS/Inno, Python, Git), встроенный Chromium,
каталог браузеров, автозапуск, защита от падений и зависаний встроенных приложений.

## Как пользоваться списком

План работ (docs/PLAN.md) берёт задачи сверху вниз. Видеокарты (пункты 2, 3, 109) пока отложены по решению
владельца проекта. Ближайшие кандидаты: менеджер языков и ввод на других языках (13), микрофон и раздел
«Устройства» (15, 61), exFAT/NTFS для флешек и дисков Windows (9), ACPI‑выключение и сон (4, 5), Wi‑Fi (1).
