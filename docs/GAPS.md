# Чего нет в SynthOS по сравнению с Windows и macOS

Список сверен с версией 1.2 «Nebula» (начат для 1.1 «Black Hole»). В нём то, что есть в Windows 11 или macOS и чего пока нет
в SynthOS (или есть только часть). Пункты отсортированы по важности для обычного пользователя: сверху то,
без чего систему трудно использовать каждый день, внизу то, что нужно немногим.

Обозначения: **W** есть в Windows, **M** есть в macOS. «Частично» значит, что в SynthOS есть начало, но
до уровня W/M далеко.

Обновлено 19.11.2026 после сверки с исходным кодом. Полностью реализованные пункты удалены. Номера сохранены,
чтобы ссылки в [PLAN.md](PLAN.md) и TASKS.md не сломались, поэтому в таблицах есть пропуски. Пункты, найденные
при аудите (баги и недочёты в уже сделанном), — в конце, после раздела «Что SynthOS уже умеет».

## Что SynthOS уже умеет (для сравнения)

Свой загрузчик BIOS/UEFI с Secure Boot, 64‑битное ядро (и 32‑битное для старых ПК), установка рядом с Windows,
диски IDE/AHCI/NVMe/USB (в том числе Intel RST/VMD), звук HDA, сеть с HTTPS (TLS 1.3), рабочий стол в стиле
macOS с Liquid Glass, Dock, строкой меню, Пунктом управления, Mission Control и рабочими столами, виджеты,
снимки экрана с редактором, Quick Look, поиск по содержимому файлов, пользователи с паролями и экран блокировки,
запуск 32‑ и 64‑битных программ Windows (Chromium, Firefox, установщики MSI/NSIS/Inno, Python, Git), встроенный
браузер, каталог браузеров, автозапуск, защита от падений и зависаний встроенных приложений.
Закрыто за последние версии: корзина с восстановлением, обновления из сети и с флешки, языки и IME (корейский,
японский, китайский), VPN (WireGuard, OpenVPN, IKEv2), прокси и DHCPv6, ночной режим и тема по времени, фото с
индексом лиц, Task Scheduler, Device Manager, журнал событий, калькулятор, новости/котировки/спорт, восстановление
системы, Thunderbolt, PDF и Office (просмотр), FLAC/MP3/Ogg/WebP/TIFF, экранная запись, сохранение сессии,
кнопка питания и крышка ноутбука (прерывание SCI, события GPE, встроенный контроллер, свой интерпретатор AML).

## Как пользоваться списком

План работ (docs/PLAN.md) берёт задачи сверху вниз. Видеокарты (пункты 2, 3, 109) пока отложены по решению
владельца проекта. Ближайшие кандидаты: микрофон и выбор устройства ввода (15), exFAT/NTFS для флешек и дисков
Windows (9), кнопка питания и крышка (4), сон (5), Wi‑Fi (1), шифрование диска (33), SSH (90). Недочёты из раздела
ниже стоит закрыть раньше новых функций: это дешёвые исправления, которые касаются каждого, кто собирает систему.
