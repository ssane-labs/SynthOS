# Видеокарты и 3D: план до Counter‑Strike 2

Цель — запустить CS2 (Windows‑версию через слой совместимости SynthOS). Ниже честно: что нужно, в каком порядке и что уже сделано.

## Что требует CS2

- Windows x64, Steam‑клиент (Chromium‑интерфейс), античит VAC (в пользовательском режиме).
- **Direct3D 11** (Source 2; на Linux — Vulkan). Шейдеры DXBC Shader Model 5.0.
- Процессор с SSE4.2/AVX, 8 ГБ памяти, видеокарта с 1 ГБ памяти и выше.
- Сеть (UDP, Steam Datagram Relay), звук (XAudio2/WASAPI), сырой ввод мыши.

## Порядок работ

| Этап | Что | Состояние |
|---|---|---|
| 1 | Смена режимов без VBE/GOP: Bochs DISPI (QEMU, VirtualBox) | сделано |
| 2 | **virtio‑gpu 2D**: PCI virtio 1.x, очереди, ресурс‑экран в памяти, перенос и показ изменённых областей, несколько экранов | сделано (64‑бит) |
| 3 | virtio‑gpu: аппаратный указатель (cursorq), синхронизация с кадром (fence) | дальше |
| 4 | Общий слой GPU в ядре: буферы команд, объекты памяти, синхронизация, планировщик | дальше |
| 5 | Программный растеризатор (запасной путь для любого ПК): треугольники, глубина, текстуры, смешивание, AVX2 на всех ядрах | дальше |
| 6 | Транслятор шейдеров DXBC SM4/SM5 → машинный код x86 (для 5) | дальше |
| 7 | **Direct3D 11** в слое Win32 (d3d11.dll, dxgi.dll) поверх 4–6 | дальше |
| 8 | virtio‑gpu 3D (virgl/Venus) — настоящая видеокарта хоста в виртуальной машине | дальше |
| 9 | Intel Gen9–Xe: дисплей (DDI, eDP/HDMI/DP), GTT, кольца команд, блиттер, затем 3D‑конвейер | дальше |
| 10 | AMD (GCN/RDNA) и NVIDIA — после Intel; NVIDIA — только через открытые модули GSP | дальше |
| 11 | Vulkan (для DXVK‑подобного пути и родных игр), Direct3D 9/10/12 | дальше |
| 12 | Steam‑клиент: CEF/Chromium в слое Win32, затем CS2 | дальше |

## Почему так

- Без своей видеокарты игра всё равно не пойдёт: нужен D3D11. Поэтому сначала программный путь (5–7) — он работает везде и
  проверяется в QEMU, а аппаратные драйверы (8–10) потом подменяют его исполнитель.
- Настоящие драйверы Intel/AMD/NVIDIA — годы работы большой команды в Linux; здесь они пишутся с нуля по открытой
  документации (Intel PRM, AMD ISA/register docs), начиная с Intel — у него самая полная открытая документация.

## Проверка

```bash
make
QEMU_EXTRA="-vga none -device virtio-vga" sh tests/shot.sh build/vga/synthos.img shot.png 16
```

В журнале (`dmesg | grep display`) — `virtio-gpu with 1 display, 1280x800`.
