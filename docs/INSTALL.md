# Установка SynthOS на компьютер

Два пути, оба без захода в настройки BIOS/UEFI:

* **Из Windows, без флешки** (проще всего) — скачать архив, запустить `Install SynthOS.cmd`,
  перезагрузиться. Раздел 0.
* **С флешки** — записать образ, загрузиться с него, «Install SynthOS». Разделы 1–5.

Готовые файлы лежат в релизе **latest** на GitHub (страница репозитория → **Releases** → «SynthOS
(latest build)»; прямые ссылки — `…/releases/latest/download/synthos-windows.zip` и
`…/releases/latest/download/synthos-usb.zip`). Релиз обновляется после каждого изменения кода;
собирать ничего не нужно.

## 0. Установка из Windows (без флешки)

1. Скачать `synthos-windows.zip` из релиза и распаковать **целиком** (например, на Рабочий стол).
2. Дважды щёлкнуть **`Install SynthOS.cmd`** и разрешить запуск от имени администратора. Если
   Windows покажет «Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».
3. Ввести, сколько гигабайт отдать SynthOS (по умолчанию 32; Windows остаётся не меньше 15 ГБ
   свободного места), и подтвердить.

Что делает установщик:

* сжимает диск C: на выбранный размер (как «Сжать том» в «Управлении дисками»; файлы Windows не
  трогаются) и создаёт в освободившемся месте раздел SynthOS — система, Chromium и ваши файлы;
* кладёт загрузчик в раздел EFI Windows (`\EFI\SynthOS`) и ядро рядом (`\SYNTHOS`);
* добавляет пункт «SynthOS» в меню загрузки компьютера (`bcdedit`) и один раз запускает его при
  следующей перезагрузке — поэтому не нужны ни флешка, ни клавиша меню загрузки, ни выключение
  Fast Boot;
* если включён BitLocker, приостанавливает его на две перезагрузки.

После перезагрузки запускается SynthOS с мастером первого запуска (раздел 6). Дальше при каждом
включении — меню SynthOS / Windows на 3 секунды (раздел 5).

**Secure Boot выключать не нужно.** Если он включён, при первом запуске один раз появится синий
экран MokManager (подробно — в разделе 2): «OK» → любая клавиша → **Enroll key from disk** → раздел
EFI → `SYNTHOS` → `SYNTHOS.CER` → **Continue** → **Yes** → **Reboot**.

Удаление — `Uninstall SynthOS.cmd` из того же архива: раздел SynthOS, его файлы в разделе EFI и пункт
меню удаляются, место возвращается диску C:.

Параметры для опытных: `install.ps1 -SizeGB 64 -Yes -NoRestart` (PowerShell от администратора).

Нужно: Windows 10/11 в режиме UEFI на диске GPT (так установлены практически все компьютеры с 2012
года). Если Windows стоит в старом режиме Legacy BIOS, установщик скажет об этом — тогда путь с
флешки на отдельный диск.

## 1. Загрузочная флешка

Нужна флешка от 1 ГБ (всё, что на ней было, сотрётся).

1. Скачать `synthos-usb.zip` из релиза и распаковать: внутри `synthos-usb.img` и его контрольная
   сумма `synthos-usb.img.sha256`. (Тот же образ лежит в **Actions** → «USB image» → последний
   запуск → **Artifacts** → `synthos-usb`, там нужен вход на GitHub.)

   **Собрать самому** (Linux или WSL, пакеты — в INSTRUCTIONS.md, раздел 2):

   ```sh
   make usb        # build/synthos-usb.img и build/synthos-usb.img.sha256
   make windows    # build/synthos-windows.zip — установка из Windows
   ```

   Он компактный (система, Chromium и 64 МБ под данные); при первом запуске раздел данных сам
   растягивается на всю флешку, так что флешку можно использовать как «живую» систему со своими
   файлами.

2. Записать образ **побайтно**:
   * **Windows** — [Rufus](https://rufus.ie): «Устройство» — флешка, «Метод загрузки» — выбрать
     `synthos-usb.img`; на вопрос о режиме записи ответить **DD-образ**. Или
     [balenaEtcher](https://etcher.balena.io): Flash from file → флешка → Flash.
   * **macOS** — balenaEtcher, или в терминале:
     `diskutil list`, `diskutil unmountDisk /dev/diskN`,
     `sudo dd if=build/synthos-usb.img of=/dev/rdiskN bs=1m`.
   * **Linux / WSL** — `lsblk`, затем
     `sudo dd if=build/synthos-usb.img of=/dev/sdX bs=4M status=progress conv=fsync`
     (sdX — именно флешка, не системный диск!).

## 2. Настройки прошивки — менять не нужно

* **Secure Boot** — можно оставить включённым. На флешке (и в установке из Windows) первым
  запускается **shim** — загрузчик, подписанный Microsoft (тот же, что у Ubuntu), поэтому
  прошивка с заводскими ключами его пускает. Ключ SynthOS shim узнаёт из своего списка MOK, который
  заполняется один раз на синем экране **MokManager**:
  1. «Verification failed: (0x1A) Security Violation» → **OK**;
  2. «Press any key to perform MOK management» → любая клавиша (на это 10 секунд);
  3. **Enroll key from disk** → выбрать раздел (флешку `SYNTHOS` или раздел EFI) → `SYNTHOS/` →
     `SYNTHOS.CER`;
  4. **Continue** → **Yes** → **Reboot**.

  Ключи прошивки и Windows при этом не меняются, BitLocker ничего не замечает. Если shim не нравится,
  по-прежнему можно добавить `SYNTHOS\SYNTHOS.CER` в db прошивки (Append, не Replace) или выключить
  Secure Boot.
* **Режим SATA** — подходит и AHCI, и «RAID / Intel RST» (без собранного RAID-массива): контроллер в
  режиме RAID SynthOS использует как AHCI, а NVMe-диски за Intel VMD («VMD controller», ноутбуки с
  11-го поколения Intel) находит сам.
* **Fast Boot** — можно не выключать. Если флешки нет в меню загрузки: в Windows «Пуск» → «Питание» →
  удерживая **Shift**, «Перезагрузка» → «Использовать устройство» → флешка. Так прошивка видит USB даже
  с Fast Boot.
* **Режим загрузки** — UEFI (как у Windows 10/11). Старый Legacy/CSM тоже работает, но тогда
  ставить только на весь диск.

**BitLocker.** Установка из Windows приостанавливает его сама. Если вы всё-таки меняете настройки
прошивки (выключаете Secure Boot или меняете ключи), сначала сохраните ключ восстановления
(account.microsoft.com/devices/recoverykey) или приостановите защиту:
`manage-bde -protectors -disable C: -RebootCount 3` (командная строка от администратора).

Под Secure Boot загрузчик запускает только то ядро, с которым он был подписан. Ключ создаётся при
сборке (`keys/db.key`); в готовых образах из GitHub он одинаковый для всех сборок, если в репозитории
заданы секреты `SB_KEY`/`SB_CERT` (PEM), иначе у каждой сборки свой и после обновления шаг MokManager
повторяется один раз.

## 3. Загрузка с флешки

Вставить флешку, перезагрузить компьютер и выбрать её в меню загрузки (обычно F12, F11, F8 или Esc
сразу после включения). Появится экран «Welcome to SynthOS»:

* **Try SynthOS** — работать прямо с флешки, ничего на компьютере не меняя;
* **Install SynthOS** — открыть установщик (он же есть в Dock и в Launchpad).

## 4. Установщик

1. **Which disk?** — выбрать диск (флешка, с которой идёт загрузка, в списке не показывается).
2. **Where on the disk?** — сверху карта диска: каждый раздел в масштабе, с типом, размером и
   меткой. Варианты:
   * **Next to the other systems, in N GB of free space** — в неразмеченное место; ни один
     существующий раздел не меняется. Это вариант «рядом с Windows».
   * **Instead of partition N** — удалить выбранный раздел (например, ненужный диск D:) и
     поставить SynthOS на его место; остальные разделы не трогаются. Раздел EFI и служебный
     раздел Microsoft (MSR) заменить нельзя.
   * **The whole disk** — стереть весь диск и отдать его SynthOS.

   **Как выделить место от раздела Windows.** SynthOS сам не уменьшает раздел NTFS — это
   надёжнее сделать средствами Windows: Win+X → «Управление дисками» → правой кнопкой по C: →
   «Сжать том» → указать, сколько МБ отдать (например, 30000 для 30 ГБ). Появится
   «Не распределено» — после перезагрузки с флешки установщик покажет это место как вариант
   «Next to the other systems». Если места не хватает, установщик сам подскажет это.
3. **How much space for SynthOS?** — ползунок (или кнопки Smallest / 16 GB / 64 GB / All, или
   стрелки ←/→ по 1 ГБ). Остаток свободного места остаётся свободным.
4. **Ready to install** — сводка: диск, куда, сколько места, что будет стёрто (красным, если
   что-то стирается). Переключатель «Bring my files and settings» переносит `/home` с флешки.
   Только кнопка **Install** / **Erase and Install** что-либо записывает.
5. Копирование (~1 минута) и **Restart**.

Что создаётся на диске при установке «рядом»:

| Раздел | Размер | Что внутри |
|---|---|---|
| SynthOS EFI (тип EFI System) | 12 МБ | shim `\EFI\BOOT\BOOTX64.EFI`, загрузчик `grubx64.efi`, MokManager, ядро, `\SYNTHOS\SYSTEM.CFG` |
| SynthOS | остальное | загрузочная область, Chromium, раздел данных (`/home`) |

Раздел EFI Windows не изменяется — у SynthOS свой.

## 5. Первая перезагрузка и меню загрузки

После **Restart** оставьте флешку вставленной: загрузчик с флешки находит новую установку,
добавляет пункт **SynthOS** в меню загрузки компьютера (переменные UEFI `Boot####` и
`BootOrder`) и сразу запускает систему с диска. После этого флешку можно вынуть.

При каждом включении, если на компьютере есть другие системы, SynthOS показывает меню:

```
  SynthOS boot menu

  > SynthOS
    Windows Boot Manager

  Up and Down (or a number) choose, Enter starts.  SynthOS starts in 3 s.
```

Выбор Windows запускает её штатно — через прошивку (`BootNext` и перезапуск), а не изнутри
загрузчика SynthOS, поэтому BitLocker и обновления Windows ведут себя как обычно. Время ожидания —
строка `timeout=` в `\SYNTHOS\SYSTEM.CFG` на разделе SynthOS EFI (0 — без меню).

Если обновление Windows поставило свой пункт первым — выберите SynthOS в меню загрузки прошивки
(F12/F11/F8) или поднимите его в настройках UEFI (Boot Order).

## 6. Мастер первого запуска

При первом запуске установленной системы:

1. **Hello** — приветствие.
2. **Keyboard and region** — раскладки клавиатуры (English US всегда; Russian, German, French,
   Spanish), часовой пояс (←/→), 24-часовой формат. Интерфейс системы — на английском; печатать
   можно на любом выбранном языке.
3. **Your account** — имя, имя учётной записи (подставляется само: «Anna Smith» → `anna`),
   пароль (можно оставить пустым), «Log in automatically». Tab переходит между полями.
4. **Choose your look** — Dune / Mist / Night, светлый/тёмный режим, цвет акцента; рабочий стол
   за карточкой меняется сразу.
5. **Your web browser** — Chromium (уже установлен, работает без сети) или Google Chrome
   (скачивается и ставится при первом открытии).
6. **All set** → **Start** — создаётся учётная запись и выполняется вход.

Всё это потом меняется в System Settings; мастер можно запустить снова командой `welcome`.

**Раскладки.** Переключение — **Win+Space** или щелчок по буквам (EN/RU…) в строке состояния.
Набирать можно в полях приложений, в Блокноте и в Windows-программах; в Терминале команды
вводятся латиницей. Включить раскладки позже: System Settings → Keyboard → Input Sources или
`config keyboard us,ru`.

## 7. Из терминала

```
install                                   диски, их разделы и свободное место
install sda --free 1 --size 30000 --yes   в первое свободное место, 30 ГБ
install sda --replace 4 --yes             вместо раздела 4
install sda --whole --yes                 на весь диск
install ... --copy-home                   перенести /home
part [диск]                               таблица разделов (MBR/GPT)
part sdb init gpt --yes                   новая пустая таблица GPT
part sdb add 512 data Docs --yes          добавить раздел на 512 МБ
part sdb del 2 --yes                      удалить раздел 2
welcome                                   мастер первого запуска
```

## 8. Удаление SynthOS

Поставленный из Windows — `Uninstall SynthOS.cmd` из архива (раздел 0). Поставленный с флешки — в Windows: «Управление дисками» → удалить разделы «SynthOS» и «SynthOS EFI» (для раздела EFI
понадобится `diskpart`: `select disk N`, `select partition M`, `delete partition override`),
затем расширить соседний раздел. Пункт SynthOS в меню загрузки удаляется командой
`bcdedit /enum firmware` → `bcdedit /delete {идентификатор}` или в настройках UEFI.

## 9. Если что-то пошло не так

* **Флешка не видна в меню загрузки** — загрузиться с неё через Windows: Shift + «Перезагрузка» →
  «Использовать устройство»; записать образ заново в режиме DD. Или поставить из Windows без флешки
  (раздел 0).
* **Синий экран «Verification failed: (0x1A) Security Violation»** — это shim: ключ SynthOS ещё не
  добавлен. «OK» и дальше по шагам из раздела 2 (MokManager).
* **«Access Denied» / ничего не происходит, MokManager не появляется** — прошивка не доверяет и
  загрузчику Microsoft для сторонних систем (на некоторых ноутбуках с «Secured-core» это выключено:
  в настройках Secure Boot включить «Allow Microsoft 3rd Party UEFI CA»), либо образ собран без shim:
  добавить `SYNTHOS\SYNTHOS.CER` в db (п. 2) или выключить Secure Boot.
* **«Secure Boot: KERNEL.BIN is not the kernel this loader was signed with»** — ядро на флешке
  заменено или повреждено: записать образ заново.
* **Установщик не видит диск** — `dmesg | grep -E "ahci|nvme|vmd"` покажет, что найдено. Собранный
  RAID-массив SynthOS не читает; если не помогло и в режиме «RAID / RST», переключить SATA на AHCI
  (Windows тогда сначала загрузить в безопасном режиме, иначе она может не найти свой диск).
* **Нет варианта «рядом с Windows»** — нет неразмеченного места нужного размера: сжать том в
  Windows (см. п. 4). Диски больше 2 ТБ с GPT пока доступны только целиком.
* **После установки грузится сразу Windows** — загрузиться один раз с флешкой (она добавит
  SynthOS в меню) или выбрать «SynthOS» в меню загрузки прошивки. После установки из Windows:
  в Windows `bcdedit /enum firmware` должен показать пункт «SynthOS»; запустить его один раз —
  `bcdedit /set {fwbootmgr} bootsequence {идентификатор}` и перезагрузиться.
* **Компьютер в режиме Legacy BIOS** — установка «рядом» требует UEFI; на весь диск можно и в BIOS.

## 10. Что поддерживается из оборудования

* **Экран** — через видеорежим прошивки (UEFI GOP или VESA): разрешение то, что выставила прошивка,
  без ускорения видеокартой. Драйверов NVIDIA/AMD/Intel для 3D пока нет, поэтому игры на
  Direct3D/Vulkan не запускаются.
* **Диски** — SATA (AHCI, а также режим «RAID / Intel RST» без массива), NVMe (в том числе за Intel
  VMD), старые IDE, USB-флешки и USB-диски. Собранные RAID-массивы (два диска как один) — нет.
* **Клавиатура и мышь** — USB (xHCI) и PS/2; тачпады ноутбуков работают, если прошивка показывает
  их как PS/2- или USB-мышь (часто — нет, тогда нужна USB-мышь).
* **Сеть** — только проводная: Intel (e1000/e1000e) и Realtek (RTL8139, RTL8111/8168/8125).
  Wi-Fi нет — используйте кабель или USB-Ethernet с этими чипами.
* **Звук** — Intel HD Audio (почти все компьютеры с 2005 года) с кодеками **Realtek** (ALC…),
  Conexant, IDT, VIA, Cirrus и другими: динамики, наушники (при подключении наушников динамики
  выключаются), линейный выход; HDMI-звук пока нет. На старых платах и в виртуальных машинах — AC'97.
  Проверка: `sound` (какое устройство найдено) и `sound test` (тон 440 Гц).

* **Процессор** — любой 64-битный (x86-64, то есть почти все ПК с 2006 года). Для совсем старых
  компьютеров (от i486) есть 32-битная сборка: `make ARCH=i686 usb` → `build/synthos-usb32.img`
  (в готовых образах — артефакт `synthos-usb32`).

Если что-то не работает, систему можно запускать с флешки («Try SynthOS») без установки — так
проще проверить компьютер.
