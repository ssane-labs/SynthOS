MS-DOS PROGRAMS
===============

SynthOS runs .COM and .EXE (MZ) programs written for MS-DOS in a built-in
8086/80186 emulator, so they work on any processor SynthOS runs on.

  hello.com            run from /dos (it is in PATH) or any directory
  run game.exe args    explicit form
  echo $?              exit code returned by the program

Supported
  INT 21h: console, files and directories, find first/next, memory
           (MCB chain), exec of child programs, date/time, IOCTL basics
  INT 10h: text mode 80x25, cursor, scrolling, write char/string
  INT 16h keyboard, INT 1Ah clock, INT 15h wait, timer interrupt 8/1Ch
  Direct writes to video memory at B800:0000 (shown with VGA colors)
  Output redirection: 'files.com > log.txt' captures DOS output
  COMMAND.COM /C runs SynthOS shell commands

Not yet
  Graphics modes (CGA/EGA/VGA 320x200), sound, 386 instructions,
  EMS/XMS memory, mouse.

Drive C: is the SynthOS root directory, so C:\HOME\FILE.TXT is
/home/file.txt. Names are matched without regard to case.
Ctrl+C stops a running program.
