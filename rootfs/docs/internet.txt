INTERNET
========

The network card gets an address by DHCP when SynthOS starts
(Intel e1000/e1000e, Realtek RTL8139/RTL8169; QEMU's default card works).

  ifconfig                 address, mask, gateway, DNS of each card
  dhcp                     ask for an address again
  ping example.com         check that a host answers
  nslookup example.com     look up an address
  netstat                  open connections

Web
  launch chromium [url]    Chromium, the browser that comes with SynthOS
  launch chrome [url]      Google Chrome (downloads itself the first time)
  browse URL|file.html     show a page as text, links numbered at the end
  wget -O file URL         download a file;  wget -O - URL  prints it
  httpd [port] [dir]       serve a folder over HTTP until Ctrl+C

Chromium
  The image carries Chromium (the open browser Chrome is built on) in an
  area of the disk of its own. A few seconds after the first login it is
  unpacked into /home/apps/chromium without any network (a bar under the
  Dock icon shows how far it got) and from then on it opens at once; links
  and .html files open in it. bundle shows what the image carries,
  bundle extract dir unpacks it by hand.

Chrome
  Google Chrome is there too: launch Chrome. On an image without Chromium
  the Chrome icon in the Dock starts Google Chrome. Shortly after the first
  login SynthOS fetches it by itself in the background (a bar under the
  Dock icon shows how far it got; config chromeauto off stops that). It
  asks Google's update server for the current version, downloads the
  offline package gzip-compressed with a 1 MB TCP window (231 MB instead of 443 MB; it needs some
  900 MB free in /home) and unpacks Chrome into /home/apps/chrome, with a
  shortcut on the desktop. The same from the shell: pkg install chrome.
  browse shows pages as text.

Security
  HTTPS uses TLS 1.3 or TLS 1.2 and checks the server certificate against
  the trusted roots in /etc/certs (the Mozilla list). To trust another
  root, copy its .pem file to /home/certs and run 'certs reload'.
  certs list               show the trusted roots
  wget -k URL              skip the certificate check (not recommended)
  cookies                  how many cookies sites have set; cookies clear
  Cookies live in memory and are forgotten at shutdown.
