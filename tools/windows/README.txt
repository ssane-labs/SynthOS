SynthOS для Windows: установка рядом с Windows без флешки

1. Распакуйте архив целиком (например, на Рабочий стол).
2. Дважды щёлкните «Install SynthOS.cmd» и разрешите запуск от администратора.
3. Укажите, сколько гигабайт отдать SynthOS (по умолчанию 32), и подтвердите.
   Диск C: уменьшится на это место; файлы Windows не трогаются.
4. Перезагрузите компьютер — запустится SynthOS. Потом при каждом включении будет меню
   SynthOS / Windows (3 секунды).

Настройки BIOS/UEFI менять не нужно: ни Secure Boot, ни Fast Boot, ни порядок загрузки.
Если Secure Boot включён, при первом запуске один раз появится синий экран MokManager:
  OK -> любая клавиша -> Enroll key from disk -> раздел EFI -> SYNTHOS -> SYNTHOS.CER ->
  Continue -> Yes -> Reboot.
Так ключ SynthOS добавляется в список shim; ключи прошивки и Windows не меняются.

Если включён BitLocker, установщик сам приостанавливает его на две перезагрузки.

Удаление: «Uninstall SynthOS.cmd» — раздел SynthOS, его файлы в разделе EFI и пункт меню
удаляются, место возвращается диску C:.

Подробно: docs/INSTALL.md в репозитории SynthOS.
