25. **Главная модель и ускорение ИИ.**
    * Главная модель ассистента по умолчанию — MiniCPM 2B последнего поколения (просили MiniCPM5-2B; если такой
      версии в GGUF нет — ближайшая доступная MiniCPM ~2B), скачивается один раз в `/home/models`.
    * Пользователь сам ставит любую модель: файл `.gguf` в `/home/models`, выбор в Настройках → AI и `ai load`;
      поддержать архитектуры, которые для этого нужны (MiniCPM, Llama, Qwen2/2.5/3, Gemma, Phi, Mistral…).
    * Скорость «как ollama на Windows»: все технологии ускорения, какие возможны в SynthOS:
      - процессор: SSE2/SSSE3, AVX, AVX2+FMA, AVX-512 (и VNNI), выбор пути при запуске по CPUID;
        квантованные скалярные произведения без распаковки в float (Q4_K×Q8_K, Q8_0×Q8_0 как в llama.cpp);
      - все ядра (уже есть hal_parallel), выравнивание и раскладка весов под кэш, mmap-подобная загрузка без копии;
      - ускорители: GPU (Vulkan/CUDA/ROCm/Metal) и NPU требуют драйверов видеокарт, которых в SynthOS нет —
        записать в GAPS, сделать интерфейс «бэкенда вычислений», чтобы драйвер GPU подключался модулем позже;
      - KV-кэш в F16/Q8, батчевый prefill, кэш префикса системного промпта между вопросами.
    * Цифры скорости (токенов/с prefill и генерации) — в `ai bench`, сравнить с llama.cpp на той же машине.

27. **Быстрое распознавание речи с перебиванием (barge-in)** — голосовой движок, а не одна модель:
    1) пользователь говорит; 2) микрофон слушает постоянно; 3) ИИ генерирует текст и сразу озвучивает его;
    4) пользователь перебивает; 5) система замечает новую речь; 6) немедленно останавливает воспроизведение;
    7) отменяет текущую генерацию текста и речи; 8) передаёт новую реплику ИИ; 9) ИИ отвечает уже на неё.
    Распознавание начинается, не дожидаясь конца длинной фразы. Составные части:
    * VAD — определение человеческой речи (как Silero VAD);
    * потоковое ASR — распознавание по ходу речи; выбрать самую быструю хорошую модель (кандидаты: Parakeet TDT,
      Whisper base/small с потоковым окном, Moonshine); за секунды на обычном процессоре;
    * потоковая LLM (уже есть: ответ по токенам), потоковый TTS (озвучивание частями по предложениям);
    * контроллер перебивания (двухэтапное подтверждение, как в Vox: короткий всплеск — пауза озвучки,
      подтверждённая речь — отмена), очистка очереди невоспроизведённого звука;
    * эхоподавление (AEC): вычитать из микрофона то, что играет динамик, чтобы ИИ не слышал сам себя.
    Ориентиры: huggingface/speech-to-speech (Silero VAD, Parakeet TDT, Qwen, Qwen3-TTS; отмена ответа при речи
    пользователя), eleven-am/vox (VAD, потоковое распознавание, конец реплики, barge-in). Код этих проектов не
    копировать в ядро без проверки лицензий — реализовать своё (как уже сделано для Whisper).
